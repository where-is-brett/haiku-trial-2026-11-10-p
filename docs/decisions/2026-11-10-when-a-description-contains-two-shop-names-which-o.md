# When a description contains two shop names, which one sets the category?

- **Date:** 10 November 2026
- **Piece:** categorise-transactions
- **Options:** A. The shop listed first in the spec's table wins, whatever its position in the description (Nothing extra; this is what the plan builds; Can be undone) · B. The shop whose name appears first in the description wins (A small change to categoryOf and two tests more; Can be undone)
- **Recommended:** table
- **Chosen:** table
- **The director's words:** none
